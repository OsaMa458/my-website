# Usama Ecom Ops — Portfolio Website

This is the rebuilt static portfolio website for Usama Ecom Ops.

## Before uploading
Place these user-owned assets in `assets/` using the exact base names below (the site supports `.png`, `.jpg`, `.jpeg`, or `.webp`):

- `apple-touch-icon`
- `favicon-32`
- `icon-512`
- `favicon-16`
- `profile_photo_cropped`

The website automatically detects the uploaded extension for these files.
